# Проверки

API и бизнес-правила проверяются тестами в `backend/tests/`. Запуск: `cd backend && pytest -q` после установки `backend/requirements-dev.txt`.

`TEST_DATABASE_URL` включает PostgreSQL; указывать только отдельную тестовую базу, поскольку тесты пересоздают таблицы. Без этой переменной быстрые тесты используют SQLite. Проверка ограничений конкурентного доступа требует PostgreSQL.

Клиент проверяется командой `npm run build` в `frontend/`. Пользовательские сценарии описаны в `docs/qa/test-plan.md`.

`tests/browser_smoke.py` проверяет регистрацию, профиль, избранное, бронирование и отмену, языки, фильтр континента, мобильное меню и отказ API в Chromium. Используйте отдельную демонстрационную среду: сценарий создаёт тестовые данные. Установка: `pip install -r tests/requirements-browser.txt`, затем `python -m playwright install chromium`. Запуск: `python tests/browser_smoke.py`. Переменные `E2E_ADMIN_EMAIL/PASSWORD` включают проверку администратора.

`tests/browser_management.py` проверяет через браузер создание направления, переводов и программы тура, расписание выездов, публикацию, редактирование и снятие с публикации. Требует `E2E_ADMIN_EMAIL/PASSWORD`, создаёт уникальные тестовые записи и оставляет проверенный тур неопубликованным. Запускается в CI после общего браузерного сценария.
