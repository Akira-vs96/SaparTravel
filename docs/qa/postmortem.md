# Дефект UI: HTTP 200 с некорректным телом

Разбор 30.10.2026. Область — фактическое падение браузерного CI и управляемое
воспроизведение. Производственный инцидент и влияние на реальных клиентов не заявляются.

| Время UTC | Наблюдение | Доказательство |
|---|---|---|
| 23.10, 08:52 | Smoke завершился с `Cannot read properties of null (reading 'items')` | [Run 39927462884](https://github.com/Akira-vs96/SaparTravel/actions/runs/39927462884) |
| 30.10, до исправления | Chromium получил JSON null / HTML прокси при HTTP 200; тест упал | [Регрессионный сценарий](../../tests/browser_invalid_response.py); исходный журнал сохранён локально |
| 30.10, после | Те же два ответа дают ошибку с повтором без JS-падения | [Браузерные проверки](../labs/lab-11/evidence/browser.json) |

Точное начало дефекта и число затронутых пользователей неизвестны. Подтверждены
один неуспешный CI run и два отрицательных входа. Потеря операций не обнаружена;
отсутствие потерь production из этого не выводится.

## Факторы системы

API-клиент превращал ошибку разбора JSON в null и возвращал её как успешные
данные. Списки ожидали объект с items. Обычный тест сети покрывал abort,
но не ответ 200 с неверным телом. Hook мог публиковать старый результат
после отмены запроса. Ни один фактор не связан с фамилией исполнителя.

## Что сработало

Перехват pageerror обнаружил сбой после happy path. GitHub сохранил точную
ошибку. Отдельная среда позволила воспроизведение без рабочей БД. Проверка
до/после выполнена тем же сценарием без ослабления контроля JS.

| Действие | Результат | Владелец проверки / срок |
|---|---|---|
| Отклонять null/невалидный JSON, кроме ожидаемого 204 | Реализовано; ошибка ru/kk/en | Бердебек Әмір, QA по WBS; review до 06.11 |
| Не публиковать ответ отменённого запроса | Реализовано в общей точке получения данных | Баекеева Бибінұр, frontend по WBS; review до 06.11 |
| Добавить оба отрицательных входа в CI | Сценарий и шаг добавлены; удалённый run фиксируется отдельно | QA/Delivery; следующий PR |

Другой участник ещё не подтвердил review. Ссылки задач — в реестре передачи.
