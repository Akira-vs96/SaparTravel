# Протокол внешнего UAT

Статус 13.11.2026: **самоприёмка владельца продукта выполнена; независимый
UAT другой команды не заявляется**.
Автоматические браузерные проверки доступны в [отчёте](../verification-results.md),
но не заменяют молчаливое наблюдение за заказчиком или другой командой.

Команды и границы локального прогона зафиксированы в
[uat-execution.md](uat-execution.md). Результат локального прогона нельзя
оформлять как решение заказчика.
Решение владельца продукта оформлено в
[uat-owner-acceptance.md](uat-owner-acceptance.md).

Дата, именованный стенд/SHA, внешние участники, наблюдатель и длительность
заполняются после проведения. Тестовые доступы выдаются приватно.

| ID | Что делает принимающий | Однозначный критерий прохождения | Внешний результат |
|---|---|---|---|
| UAT-01 | Находит тур по направлению, цене и датам | В выдаче только подходящие опубликованные предложения; пустая выдача объяснена | PASS: automation |
| UAT-02 | Выбирает выезд, двух участников и услугу | Видит полную сумму KZT и условия до подтверждения; после оформления сумма та же | PASS: automation |
| UAT-03 | Оформляет заявку и выполняет тестовую оплату | Видит подтверждение и свою заявку в кабинете, получает документ и календарь | PASS: automation |
| UAT-04 | Отменяет оплаченную заявку | Предварительная сумма совпадает с фактическим возвратом, статус и история обновлены | PASS: automation |
| UAT-05 | Оставляет обязательное поле пустым | Видит понятную подсказку, заполненные поля сохраняются, заявка не создана | PASS: automation |
| UAT-06 | Пытается открыть ссылку на чужую заявку | Чужие сведения не раскрываются, доступ отклонён | PASS: automation |
| UAT-07 | Поставщик меняет свой тур и пытается изменить чужой | Свой результат сохранён; чужой изменить невозможно | PASS: automation |
| UAT-08 | Пытается отклонить заявку без причины | Действие не выполнено, требуется причина; затем корректная отмена отражается в истории | PASS: automation |
| UAT-09 | Переключает ru/kk/en на телефоне | Главные подписи/ошибки/условия понятны; поля не теряются; горизонтального скролла нет | PASS: automation |
| UAT-10 | Создаёт P2-обращение и получает ответ поддержки | Видит обращение, срок, приоритет и содержательный ответ с дальнейшим шагом | PASS: automation |

Наблюдатель не подсказывает путь. Любое замечание, в том числе вне сценариев,
получает отдельный ID, точную формулировку принимающего, приоритет, владельца,
срок и ссылку на issue. Решение «принято / мотивированный отказ» оформляет
принимающий; пустая графа или отсутствие ответа не означает PASS.

Проверка runbook владельцем продукта выполнена по командам из
[uat-execution.md](uat-execution.md). Независимый читатель runbook не
подтверждён и не подменяется этой самопроверкой.
