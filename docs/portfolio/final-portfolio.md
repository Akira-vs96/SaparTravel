# SaparTravel: состав реализованной версии

SaparTravel — веб-приложение для поиска и бронирования путешествий по всему миру. В одной системе собраны каталог, программы туров, расписание выездов, избранное и заявки. Интерфейс и начальный каталог доступны на русском, казахском и английском языках.

## Пользовательские сценарии

Турист ищет маршрут, выбирает выезд и число участников, отправляет заявку и следит за статусом в кабинете. Поставщик создаёт предложения и даты, управляет публикацией и подтверждает заявки. Администратор расширяет географию каталога и назначает роли. Онлайн-оплата в эту версию не входит.

## Техническая реализация

- React/Vite и адаптивный интерфейс.
- FastAPI, JWT-сессии и Argon2 для паролей.
- PostgreSQL, SQLAlchemy и версионируемые миграции Alembic.
- Транзакционный учёт мест и история статусов бронирования.
- Docker Compose, прокси Nginx, генерация локальной конфигурации и резервное копирование.
- Проверки API на PostgreSQL, сборка frontend и браузерные сценарии в CI.

## Данные и границы

Начальный каталог демонстрационный: направления реальные, но цены и расписание созданы для проверки платформы. Реальные партнёры, платежи, email/SMS и внешние туристические API не подключены. Их наличие не имитируется.

## Процесс и артефакты

Сохранены требования, story map, WBS/RACI, риски и исходные учебные материалы. ADR-001 описывает Scrum с двухнедельными спринтами; ADR-002 фиксирует переход на обычный PostgreSQL и собственный API. Актуальные команды запуска, проверки и эксплуатации находятся в README и runbook.
