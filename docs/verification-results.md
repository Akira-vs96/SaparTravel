### Контрольный отказ и восстановление SLI-R / SLI-D

Финальный полный браузерный прогон **ACCEPTED**: API был остановлен,
отказ зафиксирован из всех трёх локальных точек, архив восстановлен в новую
БД, затем API запущен с восстановленной БД. Пять реальных последовательных
UTC-минут дали **3/3 успешные точки в каждой минуте** (15/15 сценариев).
Ни ускоренного интервала, ни повторов неуспешной минуты не использовалось.

- RTO: **36.019 с** при пороге 900 с; первая успешная минута
  `2026-10-30T05:00:00+00:00`, подтверждение пятой
  `2026-10-30T05:04:00+00:00`.
- RPO, верхняя граница: **0.201 с** при пороге 86 400 с;
  сверены **37 таблиц / 1516 строк**, совпадение со snapshot подтверждено.
- Собственно restore: **0.400 с**. Это время восстановления
  БД отдельно от полного RTO пользовательского сценария.

[Итоговый JSON](ops/evidence/2026-10-30/recovery.json) и
[первичные минутные наблюдения](ops/evidence/2026-10-30/recovery-probes.jsonl)
содержат также исходный наблюдавшийся отказ. Вложенный `database.sli_r_confirmed`
описывает ограниченную проверку БД; подтверждение полного SLI-R находится в корне отчёта.

В ходе проверки исправлен дефект измерителя: холодный запуск и закрытие
Chromium попадали в HTTP-таймер. Теперь браузер готовится до начала сценария,
а навигация с отрисовкой каталога по-прежнему ограничена 2 с; медленный HTTP
и сломанное приложение проверены отрицательными браузерными тестами.
Финальный прогон выполнен после исправления. Все три клиента используют один
компьютер, поэтому `independent_points: false`: это локальная приёмочная
проверка восстановления, а не доказательство внешнего мониторинга или месячного SLA.

### Ограничения передачи

GitHub Actions настроен для основных проверок и полного профиля
[service-level-acceptance](../.github/workflows/service-level-acceptance.yml);
удалённый запуск из этого сеанса **не выполнялся**. В backend осталось
предупреждение совместимости Starlette TestClient/AnyIO; проверки не отключались.
Нового сканирования образов Trivy не проводилось.

Постоянные внешние точки, публичный HTTPS/домен, off-site хранилище, дежурство
и канал аварийного оповещения требуют предоставленной инфраструктуры и доступов.
Вторая копия в отдельном локальном каталоге проверяет перенос/целостность,
но не доказывает off-site размещение. Регулярные timers на временном стенде
не включались. URL/три независимых узла запрошены, но не предоставлены.

Нет полного месяца эксплуатационных наблюдений: доступность 99,9%/99,5%
не заявляется. Праздничный календарь, плата F, ответственные, дата начала SLA
и договорные реквизиты остаются на согласовании; примеры имеют `approved: false`.
Автотесты не заменяют демонстрацию и явную приёмку D1–D4 заказчиком.

Этот этап расширяет предыдущую проверку SOW на все 15 лабораторных.
[Реестр](labs/README.md) сохраняет каждый нумерованный шаг и пункт проверки;
[архитектура](architecture.md) разделяет приложение, эксплуатационные
инструменты, расчёты курса и документы каждой работы.

- Backend: **86 тестов**, покрытие **86,17%**, PostgreSQL 17 / Python 3.13.5,
  порог 60%. Повторено после обязательной причины staff-отмены и связывания
  AuditLog с серверным X-Request-ID. [Результат](labs/lab-10/evidence/backend-coverage.json).
- **67 тестов инструментов** (49 эксплуатационных + 18 расчётов/аудита), Ruff
  без ошибок. [Результат](labs/evidence/tool-tests.json).
- **8 браузерных сценариев** на настоящем Chromium и отдельной БД:
  [результат](labs/lab-11/evidence/browser.json). Новый сценарий воспроизводит
  HTTP 200 с null/HTML и подтверждает обработку без JS-падения. Этот прогон
  предшествует добавлению поля request_id в аудит, которое проверено API-тестом.
- Дашборд: шесть панелей, фильтры 4/2, ширина 360 px без горизонтального
  переполнения и ошибок JS. [Результат](labs/lab-14/evidence/dashboard-browser.json).
- Monte Carlo: исходная внешняя история, 10 000 итераций, seed 42,
  сохранены нулевые недели. Notebook выполнен чистым kernel, 5/5 ячеек,
  0 ошибок. [Доказательство](labs/lab-06/evidence/notebook.json).
- Gitleaks/Trivy: реальные бинарные сканеры, закреплённые версии, машинные
  отчёты и точные исключения шести старых тестовых совпадений.
  [Область и ограничения](security/security-scan-report.md).
- Экономика: EMV **62 ч**, разрыв capacity **9 ч**; актуальная XLSX
  пересчитана LibreOffice, независимые Checks пройдены.
  [Корректировки](labs/lab-08/corrections.md).
- ИИ: 60 реальных локальных выводов по 30 карточкам; baseline превосходит
  модель. Ответы и отрицательное решение сохранены. Разметка Codex не
  объявляется эталоном двух независимых людей.
  [Результат](labs/lab-12/README.md), [ADR](adr/ADR-005.md).
- Два PM-отчёта собраны по GitHub; журнал фиксирует смысловые ошибки модели.
  Ручные baseline, человеческое review и экономия времени ещё не измерены.
  [Результат](labs/lab-13/README.md).

Структурная проверка не означает завершения курса: обязательные интервью,
согласования, два недельных спринта, внешние UAT/runbook, разметка и защиты
ещё требуют фактического участия людей. Публичность исходного репозитория
и закрытость Project зафиксированы; доступ преподавателя не подтверждён.
Обновлённые результаты удалённого CI фиксируются отдельно после запуска.
