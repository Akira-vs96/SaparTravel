# Измеримые нефункциональные требования SaparTravel

Версия 30.10.2026. Это критерии; фактические результаты и ограничения — в [журнале](../verification-results.md), правила SLA — в [SOW](../sow-sla-slo-sli.md).

| ID | Категория и число | Способ проверки |
|---|---|---|
| NFR-01 | Каталог: 500 туров, 20 RPS, 120+600 с; p95 ≤500 мс, 0 ошибок/потерь | scripts.catalog_load, внешний процесс и JSON стенда |
| NFR-02 | Основной сценарий: шаг ≤2 с, весь ≤10 с | Chromium и HTTP availability_probe |
| NFR-03 | SLO ≥99,9%, SLA ≥99,5% за календарный месяц | Кворум 2/3 независимых точек; месяц Алматы; пропуски неуспешны; SLA только после активации |
| NFR-04 | RTO ≤900 с, подтверждение 5 последовательными успешными минутами | Реальный отказ API и recovery_acceptance |
| NFR-05 | RPO ≤86 400 с; контроль возраста ежедневно или чаще | Snapshot, backup/restore в новую БД, fingerprints всех таблиц |
| NFR-06 | Из 2 конкурентных запросов на последнее место успешен максимум 1 | PostgreSQL concurrency tests |
| NFR-07 | 0 успешных чужих операций в матрице турист/vendor/admin | Положительные и отрицательные API/E2E тесты |
| NFR-08 | 0 PAN/CVC в БД, browser storage и диагностике | Тесты оплаты, хранения и логов; хранится только маска |
| NFR-09 | 100% контрольных смен роли/статуса имеют автора, действие и время | API audit/history tests и request ID в логах |
| NFR-10 | Повтор операции не даёт вторую оплату; возвраты ≤оплате | Идемпотентность, гонки и потеря HTTP-ответа |
| NFR-11 | Основные экраны и документы на 3 языках ru/kk/en | Browser localization и подтверждения |
| NFR-12 | Ширины 360/768/1440: 0 общего горизонтального скролла; Tab удерживается в диалоге, Escape закрывает | Browser visual/roles matrix; полная WCAG-сертификация не заявляется |
| NFR-13 | Сеть и HTTP 200 с null/HTML: 0 необработанных JS-ошибок; есть ошибка/повтор | browser_invalid_response и smoke |
| NFR-14 | Все 5 миграций на чистой БД; 100% контрольных старых сделок и ID сохраняются | Alembic check и PostgreSQL migration tests |
| NFR-15 | Для каждого типа ПДн до запуска указаны основание/место/доступ/срок/ответственный; 0 неутверждённых внешних передач | Чек-лист ИБ и решение назначенного ответственного |
| NFR-16 | CI: покрытие ≥60%; 0 новых секретов и 0 HIGH/CRITICAL на принятой базе | pytest-cov, Gitleaks, Trivy; полный SLI — отдельный workflow |
| NFR-17 | Поддержка P1/P2/P3: реакция ≤15/60/540 рабочих минут | Утверждённый календарь, серверный срок/автор/время и месячный SLI-S |
| NFR-18 | Число SELECT не растёт линейно в проверяемом списке; 0 повторных seed-записей | SQL-counter и repeatable-seed tests |

Владелец НФТ — PO; метод проверки согласуют QA и эксплуатация. Новая версия применяется к будущему периоду. Публичный TLS, рабочие ресурсы, правовые основания и независимость узлов не подтверждаются localhost-тестом.
