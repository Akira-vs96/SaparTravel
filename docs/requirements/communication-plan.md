# Стейкхолдеры, влияние и коммуникации

Актуализация 30.10.2026. Состав внутренней команды взят из
[WBS](../plan/wbs.md) и существующей Wiki; внешние полномочия этим не подтверждаются.

| Сторона | Влияние / интерес | Стратегия | Персональная связь |
|---|---|---|---|
| Заказчик / спонсор | Высокое / высокое | Управлять плотно; утверждение объёма и UAT | Конкретное внешнее лицо ещё не подтверждено |
| Абинсериков Нурасыл, PO/backend | Высокое / высокое | Вести backlog, фиксировать решения | Роль из WBS; полномочия от бизнеса требуют подтверждения |
| Айдар Елнара, аналитика/Scrum | Высокое / высокое | Требования и вопросы заказчику | Роль из WBS |
| Баекеева Бибінұр, frontend/данные | Высокое / высокое | Контракт UI/API и сверка данных | Роль из WBS |
| Бердебек Әмір, QA/Delivery | Высокое / высокое | Качество, выпуск, эскалация | Роль из WBS |
| Турист и поставщик | Среднее / высокое | Информировать, интервью по реальным случаям | Представители не назначены |
| ИБ / ответственный за ПДн | Высокое / среднее | Держать удовлетворённым, согласовать данные до запуска | Может остановить запуск; внешний контакт не назначен |
| Юрист / закупки | Высокое / среднее | Согласовать основания, договор и лимиты | Может остановить запуск; внешний контакт не назначен |
| Эксплуатация / владелец инфраструктуры | Высокое / высокое | Совместно принять runbook, копии и мониторинг | Нужны URL, узлы и назначенный принимающий |

| Что | Кому | Частота / срок | Канал | Владелец |
|---|---|---|---|---|
| Цель, объём и блокеры | Спонсор/PO | Еженедельно, перед изменением объёма | Краткий отчёт и журнал решения | Нурасыл |
| Вопросы по требованиям | Заказчик и пользователь | Один сводный пакет дважды в неделю | Issue с вариантами и сроком ответа | Елнара |
| Демонстрация инкремента | Пользователи, заказчик | Конец согласованной итерации | Живой стенд, протокол замечаний | Бибінұр / Әмір |
| Критический дефект | PO и эксплуатация | Сразу после подтверждения | Согласованный канал инцидентов; пока не назначен | Әмір |
| ПДн/доступы/экспорт в ИИ | ИБ и юрист | До передачи данных и до запуска | Реестр согласований | Нурасыл |
| Релиз/откат | Заказчик и эксплуатация | До окна выпуска; при откате немедленно | Release issue / журнал инцидента | Әмір |
| Метрики потока и качество | Команда | Еженедельно | Дашборд и снимок исходных данных | Елнара / Әмір |

Вопросы собираются одним владельцем, дубли объединяются. У каждого вопроса
есть контекст, варианты, срок и последствие отсутствия решения. Молчание
не считается согласием; продолжается только последний согласованный объём.
Ни одного сообщения от имени команды в рамках автоматизации не отправлено.
