# ЛЗ 9. Симуляция двух спринтов

[Все лабораторные](../README.md) · [Архитектура](../../architecture.md)

## Результат и границы

По новой выгрузке GitHub Projects (36 карточек, 39 переходов) наблюдаемый throughput двух недельных окон — 3 и 0. Исправлены повторные циклы, UTC-порядок событий, дата вступления в Project и разрывы цепочки. CFD содержит все статусы и явный Unknown: найдены 13 разрывов, известно 53,09% времени статусов зафиксированной когорты. Достоверное среднее WIP, mean/p85 cycle time и закон Литтла пока не определяются. CSV, исходный снимок, SHA-256, анализ и регрессии воспроизводимы одной командой. Цели и фактическая ретроспектива/эксперимент двух спринтов не подтверждены.
