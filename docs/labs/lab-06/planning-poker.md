# Покер на 10 реальных историях — подготовка

Истории: ST-05/#17, ST-06/#18, ST-08/#20, ST-09/#21, ST-10/#22, ST-11/#23, ST-12/#24, ST-13/#25, ST-14/#26, ST-15/#27. Источник — зафиксированный GitHub snapshot; состав уточняет PO, карточки могут уже иметь реализацию, но история оценки не восстановлена.

Каждый участник сначала читает позитивный и негативный AC; первый раунд показывается одновременно по шкале 1/2/3/5/8/13. Для каждой истории записать все независимые голоса, min/max, причину разброса, уточнение границ, второй раунд и решение: готова / разбить / нужен ответ. Время и участники фиксируются после события.

Ни одного голоса или разговора не придумано. Имеющийся документ docs/lab-6-planning-poker.md — прежний материал, требующий подтверждения. Перевод S/M/L в SP и оценка velocity без фактической сессии не выполняются. Неполученные значения остаются пустыми; прогноз по SP до этого не сравним с throughput.
