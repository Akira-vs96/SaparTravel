## Результат и границы

Учебные недостающие действия разобраны в отдельном упражнении с исходными данными и расчётом; фактическая приёмка учитывается отдельно. Восемь браузерных сценариев и API прошли на отдельной БД. Новый тест воспроизвёл падение на HTTP 200 с null/HTML и подтвердил исправление. Отмена сотрудником без причины теперь отклоняется, причина сохраняется в истории. Есть 10 бизнес-сценариев UAT, стратегия, данные/среды/приоритеты дефектов и postmortem фактического CI-дефекта. Внешний UAT и runbook на другом человеке не подменены автотестами.
