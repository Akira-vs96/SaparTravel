# Артефакты измерения ИИ-подбора тура

- `zero-shot.jsonl`, `few-shot.jsonl` — по одной сырой генерации на запрос, с моделью, параметрами, временем и Gemini usage metadata.
- `rules.jsonl` — результат прозрачного regex/keyword baseline.
- `results.json` — exact match, macro/micro F1, точность по каждому слоту, поштучные ошибки и серверная постобработка. В сырых ответах сохраняется исходный JSON Gemini; оценка показывает весь маршрут запроса, включая удержание фильтров, нормализацию валюты и проверку поискового намерения.
- `cost.json` — реальные token counts Gemini и оценка 10,000/100,000 запросов по стандартному paid-тарифу на дату прайса.
- `annotation-comparison.json` — появится после заполнения двух слепых форм.
- `human-gold.jsonl` — появится только если обе формы полны, разметчики различаются и все споры PO разрешены.

Текущие тестовые запросы синтетические, а ожидаемые значения предложил ИИ. Baseline настроен рядом с ними. Метрики показывают только диагностический прогон, пока не будет реального обезличенного набора, независимой разметки и отдельного holdout.
