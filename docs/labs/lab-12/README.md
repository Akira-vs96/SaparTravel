# ЛЗ 12. План ИИ-функции: evals, стоимость, риски

[Все лабораторные](../README.md) · [Архитектура](../../architecture.md)

## Результат и границы

Работает настоящая локальная Qwen2.5-0.5B через llama.cpp CPU, с pinned weights/runtime. 30 реальных названий issues, два промпта по 30 запусков, raw replies, token counts и F1 сохранены. По предложенным ассистентом меткам правила лучше модели; ADR отклоняет автоматическое применение. Две независимые человеческие разметки и решение спорных случаев отсутствуют; качество предварительное. Стоимость API — оценка по актуальному прайсу и измеренным Qwen tokens, не реальный счёт другого tokenizer.
