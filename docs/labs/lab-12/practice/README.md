## Разметка без подмены человеческого эталона

30 примеров взяты из реальных обезличенных названий issues, в том числе сложные. Для настоящей независимой работы подготовлены [форма A](annotation-a.csv) и [форма B](annotation-b.csv): ID/текст, пустая метка/обоснование, без предложенного моделью ответа. Два разных человека размечают их отдельно, затем принимающий разбирает разногласия. Эти формы не помечаются заполненными заранее.

Ролевой пример: SIM-A относит организацию репозитория к operations, SIM-B к process; модельный PO выбирает process, поскольку речь об организации работы, а не выполнении pipeline. Второй пример различает поиск тура и резерв места. Это демонстрация арбитража, не две независимые человеческие разметки. Эталоны остаются assistant-proposed, gold_approved=false.

## Реальное качество и решение

Генератор заново считает macro F1 из сохранённых настоящих zero-shot/few-shot ответов и проверяет совпадение со сводкой. Правила: macro F1 ≈0,896; zero-shot 0; few-shot ≈0,082 на предварительных метках. Ошибки сохраняются поштучно. Разница по классам не скрывается средним; требование превосходства ИИ не выполнено.

Решение **не включать автоматическую LLM-маршрутизацию** обосновано данными. В продукте остаются правила/ручной разбор; неоднозначность → abstain. Положительный ответ ради зачёта не подставляется. [ADR](../../../adr/ADR-005.md) содержит альтернативы и критерии пересмотра.

## Стоимость

[Сохранённые server token counts](../evidence/zero-shot.jsonl) получены настоящим токенизатором Qwen. [Модель стоимости](../evidence/cost.json) использует 10 000 и 100 000 запросов, две составляющие токенов и условные 64 USD фиксированных затрат. Тариф кандидата проверен 31.10.2026: [Ministral 3 3B, input/output по 0,1 USD за миллион](https://docs.mistral.ai/inference/pricing). Но токенизаторы Qwen и API различны: ≈4,76 млн запросов/месяц — только плановая точка, реальная пропускная способность и счёт API не измерены. Передача ПДн внешнему сервису не разрешается выводом о низкой цене.
