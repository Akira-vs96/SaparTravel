## Результат и границы

Учебные недостающие действия разобраны в отдельном упражнении с исходными данными и расчётом; фактическая приёмка учитывается отдельно. Есть story map с PNG, 18 реальных историй в GitHub и негативные AC; подготовлена матрица влияния/интереса с ИБ, юристом и эксплуатацией, план коммуникаций и 18 числовых НФТ. Заметки двух реальных интервью отсутствуют: вместо придуманных цитат сохранены вопросы, структура протокола и требование связать ответы с изменением backlog.
