# ЛЗ 2: выполненное учебное упражнение

**Учебная симуляция.** Участники SIM и времена ролевых действий вымышлены; реальные источники и технические результаты отмечены отдельно. Этот разбор не удостоверяет внешнюю приёмку или личное участие.

## Три разобранных кейса

[Матрица шести критериев × три кейса](../cases.md) содержит требования, цену ошибки, регуляторику, зрелость заказчика, распределённость и контракт. Исходные кейсы преподавателя не предоставлены; здесь применены альтернативные учебные условия.

1. **SIM-C1, туристический MVP.** Требования меняются после проверки пути пользователем. Scrum, недельная проверка инкремента; переменный необязательный объём. Качество денег/мест не уменьшается ради даты.
2. **SIM-C2, миграция финансового реестра.** Инварианты сумм и окно переключения фиксированы. Гибрид: короткие прогоны и формальные ворота сверки/отката. Меняется способ реализации, а не точность данных.
3. **SIM-C3, поддержка зрелого сервиса.** Работа приходит непредсказуемо. Kanban, ежедневное пополнение очереди, немедленное рассмотрение инцидента; меняется следующий элемент очереди, WIP ограничен.

Модельная комиссия отклоняет «один Scrum для всех»: миграционный допуск нельзя заменить завершением спринта, а инцидент не ждёт следующего планирования.

## Доступ и дисциплина

Репозиторий и Wiki действительно существуют, четыре аккаунта сотрудников уже имеют доступ. Реальные имена/права сохраняются в снимках основной ЛЗ. В упражнении SIM-TEACHER должен открыть репозиторий и доску отдельной учётной записью; этот факт не отмечен состоявшимся. Приглашение нельзя создать без идентификатора человека.

Правило веток: feat/ID-name, fix/ID-name, docs/ID-name; одна задача, максимум три дня; просрочка требует разделения. Коммиты feat:/fix:/docs:, PR связан с задачей, независимый review. Настройки main допускают admin push по прямому требованию пользователя; это зафиксированное исключение, а не выполненный полный запрет.

Требование Private в текущем публичном репозитории не выполнено. Автоматически менять видимость ради галочки нельзя: публичные ссылки портфолио и Wiki перестанут выполнять свою задачу. Для настоящей сдачи нужен выбор преподавателя и проверка принимающего. Локальные документы, структура, шаблоны issue и рабочие соглашения уже подготовлены.

## Воспроизведение

Из корня: `.venv/bin/python -m scripts.course.practice`, затем `.venv/bin/python -m scripts.course.practice --check`. Общий реестр сопоставляет каждому требованию оригинала конкретный артефакт.
