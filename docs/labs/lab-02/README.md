## Результат и границы

GitHub существует: 30 карточек, 6 статусов, нужные поля, 4 collaborators и 5 Wiki-страниц. Репозиторий публичный, Project приватный; доступ преподавателя не подтверждён. Есть коммиты четырёх участников. Добавлены четыре issue-шаблона и соглашения. Вместо отсутствующих трёх кейсов преподавателя подготовлен явно обозначенный сравнительный анализ трёх контекстов; исходные кейсы нужно предоставить.
