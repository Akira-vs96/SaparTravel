# Извлечённые уроки

| Событие | Что поняли | Изменение поведения |
|---|---|---|
| Учебный throughput 4/6/0/... выглядел как прогноз | Реальная цифра без происхождения не становится данными команды | Хранить источник/период/hash; не переносить чужой темп без оговорки |
| 20 строк RAID дали 62, а итог 63,2 | Проверка формул бюджета не проверяет верность исходного агрегата | Проверять сумму источника, а не только производную таблицу |
| Резерв уже вычтен из net capacity | Сравнение полного EMV с net задваивало риск | Свести gross/отсутствия/оба резерва одним уравнением до решения по объёму |
| HTTP 200 с null/HTML сломал UI | Статус 200 недостаточен для успешного ответа | Проверять контракт в API-клиенте и два отрицательных тела в CI |
| Браузерный измеритель включал запуск Chromium в HTTP время | Измеритель сам может создавать ложные отказы | Отделять подготовку прибора от сценария, сохранять сырые минуты и реальные лимиты |
| Локальная Qwen уступила правилам | Наличие настоящей модели не доказывает пользу | Сначала baseline/независимые эталоны; при недостатке качества не включать автоматические действия |
| Зелёные CI были, deployments не было | У разных событий разные знаменатели | Вести deployment/incident IDs; отсутствие метрики показывать явно |

Это уроки по наблюдаемым событиям проекта; финальная командная ретроспектива ещё не подтверждена. Участники должны добавить собственные причины/действия, а не подписываться задним числом.
