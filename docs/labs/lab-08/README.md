## Результат и границы

SOW дополнен явным отсутствием бессрочной поддержки и механикой обмена объёма при фиксированном сроке. Сохраняются сценарии, error budget и расчёты размещения. Новая версия XLSX исправляет EMV и двойной резерв, сохраняет формулы и проходит LibreOffice/Checks. База 13 081 550,17 KZT; лимит 13 430 943,37 KZT. Пакет 23 октября оставлен историческим, тарифы не переименованы в текущие оферты. Согласование площадки для ПДн и защита пакета ещё нужны.
