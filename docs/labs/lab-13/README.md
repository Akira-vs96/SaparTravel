## Результат и границы

Выбран процесс недельного статус-отчёта из GitHub Issues, Actions и deployments. Python собирает и считает факты, Google Gemini API формулирует черновик только по агрегированным данным. Сохранены исходный API-прогон, итерации исправления промпта и два итоговых отчёта версии 6. Черновики не отправляются. Агентский разбор нашёл и проверил ошибки; подпись PM, три ручных замера и человеческое время проверки не предоставлены, поэтому чистая экономия и окупаемость не заявлены.

## Воспроизведение

```bash
.venv/bin/python -m scripts.course.practice --check
.venv/bin/python -m scripts.course.weekly_status --snapshot docs/labs/evidence/github-2026-10-30.json --start 2026-10-12T00:00:00Z --end 2026-10-19T00:00:00Z --output-directory test-results/status
```

Ключ берётся из переменной `GEMINI_API_KEY` или игнорируемого `.env`; его не
нужно вставлять в команду или коммитить.
