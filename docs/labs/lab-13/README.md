## Результат и границы

Реальный сборщик фактов и локальная модель сформировали два недельных черновика; числа считает Python. Сохранены обе версии промпта, ответы и машинная проверка чисел. Ни один отчёт не отправлен. Нет трёх ручных человеческих замеров и сплошного смыслового review, поэтому экономия/окупаемость null, а улучшение качества не заявлено без проверки.
