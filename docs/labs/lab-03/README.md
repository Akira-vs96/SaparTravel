## Результат и границы

Учебные недостающие действия разобраны в отдельном упражнении с исходными данными и расчётом; фактическая приёмка учитывается отдельно. Устав, четыре альтернативы, TCO/ROI/NPV/срок окупаемости и три стресс-сценария присутствуют. Расчёт воспроизведён: TCO 46 000 USD, NPV 9 632,11 USD при 15%, ROI за 3 года около 41,52%. Это историческая модель выгод внутренней автоматизации. Нет недели замеров заказчика, подтверждённой ставки/горизонта и факта защиты; не выдаём допущения за результаты бизнеса.
