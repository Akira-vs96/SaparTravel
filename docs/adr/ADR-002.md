# ADR-002: PostgreSQL и собственный API

Статус: принято. Дата: 2026-09-24.

## Контекст

SaparTravel развивается из демонстрационного каталога в приложение с пользователями, избранным, бронированиями и кабинетами поставщиков. Команда выбрала обычный PostgreSQL вместо Supabase. Требуются русский, казахский и английский языки. Онлайн-оплата в эту версию не входит.

## Решение

- PostgreSQL 17 — единственное рабочее хранилище; SQLAlchemy описывает модели, Alembic управляет версиями схемы.
- Браузер обращается только к FastAPI. Подключение к БД, проверка ролей и расчёт цены находятся на сервере.
- Пароли хешируются Argon2; сессия использует ограниченный по времени JWT. Роль считывается из БД при каждом защищённом запросе.
- React/Vite используют `/api/v1` на том же origin через прокси Vite или Nginx.
- Цена и вместимость относятся к конкретному выезду. Создание брони блокирует строку выезда в транзакции PostgreSQL и заново проверяет остаток мест.
- Начальное наполнение демонстрационное, включается отдельно. Реальных клиентов и общедоступных паролей администратора в seed нет.
- Переводы основных полей хранятся рядом с оригиналом; программы и списки услуг — в JSON. Снимок условий брони сохраняется намеренно, чтобы последующие изменения каталога не меняли оформленную заявку.

## Последствия

Локальную среду можно поднять без аккаунта облачного сервиса. Команда самостоятельно отвечает за резервные копии, HTTPS, почтовую инфраструктуру и сопровождение PostgreSQL. База, JWT-секрет и учётная запись администратора настраиваются через окружение. Для многопроцессного публичного размещения ограничение частоты авторизации необходимо вынести на общий шлюз или в разделяемое хранилище.

## Технические основания

Транзакционная проверка мест опирается на [блокировку строк PostgreSQL](https://www.postgresql.org/docs/17/explicit-locking.html). Авторизация следует подходу [FastAPI с хешированием паролей и JWT](https://fastapi.tiangolo.com/tutorial/security/oauth2-jwt/); работа с транзакциями — [SQLAlchemy Session](https://docs.sqlalchemy.org/en/20/orm/session_basics.html).
