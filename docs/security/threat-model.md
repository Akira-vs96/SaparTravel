# Модель угроз SaparTravel по STRIDE

**Дата:** 16.10.2026  
**Границы:** пользовательский браузер, Nginx/web, FastAPI API и PostgreSQL.
Внешние поставщики и платёжный шлюз не входят в MVP.

## Схема и границы доверия

```text
[Внешний пользователь / браузер]
              |
       TLS, boundary T1
              v
       [Nginx / React]
              |
       внутренний Docker network, T2
              v
       [FastAPI API] ---- DATABASE_URL ----> [PostgreSQL]
              |                                  |
        JWT + RBAC, T3                    volume/backup, T4
```

Файл для импорта в OWASP Threat Dragon: [threat-model.json](./threat-model.json).
На схеме отмечены внешняя граница T1 и внутренние границы T2–T4; стрелки
показывают потоки данных, а не доверие к источнику.

## STRIDE-чек

| Категория | Угроза для модели | Мера | Статус / проверка |
|---|---|---|---|
| Spoofing (подмена) | Украденный JWT используется для входа под пользователем или администратором | короткий срок токена, Argon2, ротация JWT-секрета, RBAC на API | Частично реализовано; добавить отзыв сессий в backlog |
| Tampering (изменение) | Подмена цены, роли или количества мест в запросе браузера | серверный расчёт total, Pydantic-валидация, SQLAlchemy-транзакция и запрет клиентской цены | Реализовано; покрыто API-тестами |
| Repudiation (отрицание) | Администратор отрицает изменение статуса заявки | audit event с request ID, actor, action, объектом и временем | Частично реализовано; мера B-02 |
| Information disclosure (раскрытие) | Ошибка API или логи раскрывают пароль, JWT или ПДн | обобщённые ошибки, SecretStr, no-store для auth, секреты только в `.env` | Реализовано частично; проверить логи на стенде |
| Denial of service (отказ) | Перебор auth или большой поток запросов перегружает API/БД | rate limit, таймауты, healthcheck, лимиты reverse proxy и нагрузочный smoke | Частично реализовано; мера B-03 |
| Elevation of privilege (повышение прав) | Traveler вызывает supplier/admin endpoint напрямую | серверный RBAC, проверка владельца ресурса и негативные тесты | Реализовано; добавить regression-кейс для каждой роли |

## Дополнительные условия

1. Угрозы пересматриваются при изменении границ системы, роли или внешней
   интеграции, а не только перед сдачей.
2. Каждая мера со статусом «частично» должна иметь карточку в [security-backlog.md](./security-backlog.md).
3. До публичного пилота нужно подтвердить TLS, политику ПДн и процесс отзыва
   скомпрометированных токенов.
