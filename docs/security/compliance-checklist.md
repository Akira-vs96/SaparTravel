# Чек-лист соответствия SaparTravel — ЛЗ 7

**Дата проверки:** 16.10.2026  
**Область:** демонстрационный MVP в локальном/учебном контуре. Перед
публичным запуском чек-лист должен быть подтверждён заказчиком, ответственным
за ПДн и вузом.

## 1. Обрабатываемые данные

| Данные | Цель | Основание / минимизация | Хранение | Доступ | Срок | Журнал |
|---|---|---|---|---|---|---|
| email и хэш пароля | регистрация и вход | договор/согласие пользователя; пароль не хранится в открытом виде | PostgreSQL, таблица пользователей | API auth, администратор без чтения хэша | пока аккаунт активен, затем удаление по политике | auth success/failure и request ID |
| имя пользователя | отображение профиля и заявки | согласие/исполнение заявки; обязательность проверить с PO | PostgreSQL | пользователь сам, админ по рабочей необходимости | срок действия аккаунта + утверждённый срок претензий | изменение профиля |
| контактные данные заявки | связь по заявке | исполнение заявки; собирать только нужные поля | PostgreSQL, резервная копия | пользователь, поставщик своей заявки, админ | срок договора/претензий, утвердить до пилота | создание, просмотр, статус |
| выбранный тур, выезд и сумма | исполнение и расчёт заявки | исполнение заявки; сумма считается сервером | PostgreSQL | участники конкретной заявки и админ | срок хранения заявки | status transition |
| технический IP/request ID | безопасность и диагностика | законный интерес/безопасность; не использовать для рекламы | журналы API | эксплуатация по роли | короткий срок, например 30 дней после утверждения | access log |

## 2. Контроли

| Проверка | Состояние | Действие до публичного пилота | Владелец |
|---|---|---|---|
| Цель и минимизация данных описаны | Частично | утвердить обязательные поля заявки | Абинсериков Нурасыл |
| Основание обработки и текст согласия | Не подтверждено | согласовать с ответственным за ПДн и вузом | Абинсериков Нурасыл |
| Хранение только в PostgreSQL с ограничением доступа | Реализовано для MVP | проверить права production-БД | Айдар Елнара |
| Пароли хэшируются, секреты не в Git | Реализовано | запускать Gitleaks в CI | Бердебек Әмір |
| Доступ разделён по ролям и владельцу ресурса | Реализовано в API | добавить полный regression matrix | Айдар Елнара |
| Журнал доступа и админских операций | Частично | внедрить audit event schema | Бердебек Әмір |
| Сроки удаления и резервных копий | Не утверждены | утвердить retention schedule и проверить restore | Абинсериков Нурасыл |
| Передача по TLS | Не применяется к локальному HTTP | включить HTTPS reverse proxy перед публикацией | Айдар Елнара |
| Уведомление об инциденте | Не формализовано | назначить канал и SLA уведомления | Бердебек Әмір |
| ИИ-компонент | Нет в текущем MVP | не передавать ПДн во внешние ИИ-сервисы без отдельного согласования | Абинсериков Нурасыл |

## 3. Нормативная оговорка

Для Казахстана финальная юридическая формулировка должна быть сверена с
действующей редакцией Закона РК «О персональных данных и их защите» на
официальном ресурсе [Әділет](https://adilet.zan.kz/rus/docs/Z1300000094) и с
внутренними правилами вуза. Этот учебный чек-лист не заменяет юридическое
заключение. Публичный запуск запрещён до подтверждения основания обработки,
сроков хранения, трансграничной передачи и порядка отзыва согласия.
