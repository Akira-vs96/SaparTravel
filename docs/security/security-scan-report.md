## Воспроизведение и CI

```bash
.venv/bin/python -m scripts.course.security_scan --output-directory test-results/security
```

Команда скачивает закреплённые версии официальных бинарных выпусков, сверяет
SHA-256 с контрольными суммами поставщиков и запускает настоящие сканеры.
CI использует эту же команду и сохраняет JSON даже при ошибке. Код завершения
ненулевой при находках секретов, HIGH/CRITICAL или сбое запуска сканера.

## История и исключения

До исключений Gitleaks действительно обнаружил шесть совпадений
 generic-api-key в двух тестовых файлах четырёх старых коммитов: 01aecdbe,
f2c0db35, 06348564, 04ba943a. Значения используются тестовыми fixtures;
содержимое строк здесь не публикуется. В [.gitleaksignore](../../.gitleaksignore)
перечислены только эти шесть отпечатков, каждый включает конкретный коммит,
файл, правило и строку. Новые коммиты и файлы не исключены.

Это не свидетельство утечки рабочего ключа; по доступным исходникам совпадения
относятся к тестам. Подтвердить, что эти литералы никогда не использовались во
внешнем окружении, должен владелец окружения. Если использовались, нужен отзыв
и замена ключа. Наличие исключения не является доказательством ротации.

Предыдущий текст отчёта от 16.10 перечислял CVE без сохранённого машинного
результата. Эти утверждения не используются как подтверждение текущего
состояния. Основание актуального вывода — выполненный запуск и JSON выше.
Меры и незавершённые проверки: [security backlog](security-backlog.md).
