# Оценка ИИ: реальный эксперимент ЛЗ12

[Набор 30 карточек](pm-routing/dataset.jsonl), [результаты и raw replies](../docs/labs/lab-12/evidence/), [решение ADR-005](../docs/adr/ADR-005.md).
Источник текстов — реальные названия issues SaparTravel без клиентских контактов.
Предложенные метки подготовлены ассистентом и ещё не проверены двумя людьми;
поэтому метрики diagnostic, не сертифицированное качество.

Сравниваются объяснимые правила, zero-shot и few-shot настоящей локальной
Qwen2.5-0.5B-Instruct. Temperature 0, seed 42, версия и checksum зафиксированы.
Есть 6 сложных/неоднозначных карточек. Abstain не скрывается. Классы и macro F1
считаются явными TP/FP/FN; маленький класс не исчезает в accuracy.

Команды и границы: [ЛЗ12](../docs/labs/lab-12/README.md). При повторном запуске
сохранять новый каталог результата. Для рабочего решения нужны два независимых
разметчика, разбор расхождений PO и отделённый контрольный набор; ответы
оцениваемой модели не используются для создания её же эталонов.
