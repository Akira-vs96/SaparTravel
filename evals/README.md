# Оценка ИИ: артефакты ЛЗ12

[Основная функция проекта — подбор туров](travel-assistant/README.md): 34 синтетических запроса, формы для двух независимых разметчиков и [Gemini raw replies/результаты](../docs/labs/lab-12/travel-assistant-evidence/). Эталонные фильтры пока предложены ИИ; данные не представляют реальный трафик и не сертифицируют качество.

[Дополнительный эксперимент PM-routing](pm-routing/dataset.jsonl) использует реальные названия issues SaparTravel без клиентских контактов; [результаты и raw replies](../docs/labs/lab-12/evidence/), [ADR-005](../docs/adr/ADR-005.md). Он не оценивает туристического Gemini-консультанта. Предложенные категории для issues тоже ещё не проверены двумя людьми.

Сравниваются объяснимые правила, zero-shot и few-shot настоящей локальной
Qwen2.5-0.5B-Instruct. Temperature 0, seed 42, версия и checksum зафиксированы.
Есть 6 сложных/неоднозначных карточек. Abstain не скрывается. Классы и macro F1
считаются явными TP/FP/FN; маленький класс не исчезает в accuracy.

Команды и границы: [ЛЗ12](../docs/labs/lab-12/README.md). При повторном запуске
сохранять новый каталог результата. Для рабочего решения нужны два независимых
разметчика, разбор расхождений PO и отделённый контрольный набор; ответы
оцениваемой модели не используются для создания её же эталонов.
